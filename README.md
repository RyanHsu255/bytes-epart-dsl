# Bytes EPART DSL

Bytes EPART DSL was conceived and developed by **Ryan Hsu**. It is a domain-specific language for describing the physical dimensions, connectors, and pin layouts of industrial electrical components and turning those descriptions into dimensioned drawings.

Bytes EPART DSL 由 **Ryan Hsu** 提出並開發。這是一套用來描述工業電氣元件的實體尺寸、接頭與腳位，並產出尺寸圖的領域專用語言。

## Run locally · 在本機使用

Open `index.html` in a browser and choose a built-in example. Edit the DSL to update the drawing, or enable drag mode to move supported objects and write their coordinates back to the editor. You can export SVG drawings and DXF drawings for individual `PART` views.

用瀏覽器開啟 `index.html`，選一個內建範例即可開始。修改 DSL 會即時更新圖面。開啟拖曳模式可移動支援的物件，並將座標寫回編輯器。圖面可匯出 SVG，單一 `PART` 視圖也可匯出 DXF。
