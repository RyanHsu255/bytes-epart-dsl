PART name
BODY width height [depth]  # 尺寸須大於 0，也可合寫 PART name BODY 130,90,83
VIEW FRONT | RIGHT | BACK | LEFT | TOP | BOTTOM
TERMINAL U,V AT -30,-35 PITCH 16 ROT 90
  SHAPE ROUND
  SIZE 6
  LABEL_POS K6  # 單顆、多顆皆可，無外框
LINK RIGHT @K6 SIZE 4,30  # 模組貼合介面，僅限 FRONT
CN -CN1 IDC20 AT -20,30 ROT 90 ORDER ROW
  START K1  # Pin 1 左下；亦可 K7/K9/K3
  LABEL A1..A10,B1..B10  # 按 Pin 1 起點的自然順序輸入
  NAME "INPUT" K6  # 接頭名稱置右，省略 NAME 則不顯示
  LABEL_POS K2 / K8  # 實體上排下方、實體下排上方
  # LEFT RIGHT TOP_LEFT TOP_RIGHT BOTTOM_LEFT BOTTOM_RIGHT
  PIN 1 VCC "Power input"
  PINS 2=GND 3=IN0
  PITCH 2.54
  ROW_PITCH 2.54
  STAGGER 0.5
  MARGIN 4,3
  LABEL NONE  # 不顯示端子名稱；可省略此行
BRAND "MITSUBISHI" AT 0,12 SIZE 55,6
MODEL "FX5UJ-40MT/ES" AT 0,4 SIZE 38,4
TEXT "PLC" AT 0,-10 SIZE 20,4
BOX AT 0,0 SIZE 70,30
IND LED RUN @K9
MOUNT HOLE AT -30,40 D 4.5
MOUNT STUD AT 30,40 D 4 L 12
MOUNT SLOT AT 0,-40 W 12 H 5
MOUNT DIN AT 0,0 W 80 H 35
TABLE -CN1 AT 90,65
TABLE T1 AT 90,15  # 獨立端子也可產生表格
  TITLE "CN1 pin function"

BODY、AT、SIZE、MARGIN、ANCHOR 的多個數值可用空格或逗號分隔，另存時統一用逗號。
BODY W H [D] HIDE 保留定位尺寸並隱藏本體外框，適合單獨繪製接頭。
視圖各自以中心為 (0,0)，X 向右、Y 向上。
AT 通常定位到連接器中心。錯列端子台以未錯列的針腳格中心定位，RJ45 使用模板原點。
CN 接頭 ID 可省略，依各視圖自動編為 -CN1、-CN2 等，略過已明寫的 ID。明寫時以 - 開頭。
CN -RJ RJ45 STYLE P 在原點繪製 RJ45 公頭。用 STYLE P 或 STYLE PLUG 指定公頭，用 STYLE S 或 STYLE SOCKET 指定母座。
RJ45 公頭和母座在 ROT 0 時皆預設由左至右編為 Pin 1～8。
CN 省略位置時使用原點。預設 SOCKET，MDR50M_SOLDER 固定為 PLUG。
IDC 後接偶數總腳數（2～1000）。CN IDC32 繪製 2 × 16，預設間距 2.54 mm。
@ 等效於 AT。CN TB6 @K8 依 BODY 視圖九宮格定位；K8 靠上置中，K2 靠下置中，K5 居中。
TERMINAL AT 為第一顆端子中心，TABLE AT 為表格左上角。
TABLE -CN1 K8 SPLIT 會在圖面上方分開列出奇數與偶數 Pin，K2 放下方。
開啟「拖曳模式」後，單一 PART 可拖接頭、端子或表頭，共同圖面可拖整個零件。預設以 1 mm 定位。空白處長按可插入。對齊時顯示提示線。Shift 精細定位，Alt 隱藏提示線，Esc 取消。
TABLE -A1 K2 SPLIT 可引用 SET。表格下方可直接貼 CSV，例如 X00,急停。
TABLE -CN1 K2 SPLIT 2..24 BY 2 / 1..25 BY 2 / 27..49 BY 2 / 26..50 BY 2 可指定四組 Pin。
BY 指定範圍步長。LABEL X7..X1 BY 2 由 X7 開始每隔兩個取一個。
MARGIN x[,y]：最外端 Pin 中心至外框的左右／上下距離（mm），交錯排列亦適用。
不寫 LABEL 顯示 Pin 編號；RJ45、USB 預設隱藏接點文字。LABEL NONE 隱藏接點文字，Pin 1 識別仍保留。
LABEL_POS 支援 AUTO、K1～K9 或英文方向。CN 可用 OUTSIDE 將接點文字水平排在外框兩側。
MDR50M_SOLDER 的腳號固定在焊點內，指定 LABEL_POS 時會提示。
PIN 的說明可用單引號或雙引號。PIN、PINS 的格式錯誤與越界腳號會顯示行號。
使用空格 / 空格分隔各排，以未旋轉的實體上排到下排為準，與 START 無關。
NAME "文字" [方位] 顯示接頭名稱，方位可用 K1～K9 或英文方向。NAME NONE 隱藏。TABLE 使用接頭 ID，例如 TABLE -CN1 @ 90,65。
D-sub 採圓角梯形護罩，長排在上、短排置中，預設 ORDER ROW。
START K7/K9/K1/K3 同時決定 Pin 1 的實體位置與 LABEL 的排列起點。預設 K7（左上）。ORDER ODD 沿同欄上下交錯；ORDER ROW 先排一整排。LABEL 按 Pin 1、Pin 2…自然順序，LABEL_ROWS 仍可明確指定各排。
CN 的 Pin 1 預設使用雙重輪廓（圓形或方形），可用 SHAPE 和 PIN1 覆寫。
CN 與 TERMINAL 預設 PINEND AUTO，圓形接點用半圓，矩形用直角折線。開口朝向前一腳。PINEND ARC 指定半圓，PINEND NONE 關閉。
BRAND "Name" AT x,y SIZE w,h
MODEL "Model" AT x,y SIZE w,h
TEXT "Any text" AT x,y SIZE w,h
BOX AT x,y SIZE w,h

PART MY_PLC BODY 90 90 80
PART MY_IO8 BODY 30 90 80
SET -A3
  MY_PLC
  MY_IO8

多個 PART 各自以本體中心為 (0,0)。用 PLACE A @0,0 指定 A 在共同圖面上的中心座標。
SET 優先使用文件中的 PART。並排缺少 LINK 時按本體邊緣貼齊並顯示警告；找不到型號時以灰框代替。
範例中的品牌文字以通用字型表示，非原廠商標圖樣。
FX5UJ 正視圖端子座標由使用者提供的 DXF 量測；Logo 以一般字型文字近似。連接器外框、Logo 與背面安裝仍為示意。
